QUICKSTART

极客友好的极简部署

单 Go 二进制与 TimescaleDB 配合，无复杂的 npm 前端构建，两分钟启动属于你自己的资本雷达。

bash · quickstart.sh
# 1. 克隆代码仓库
git clone https://github.com/zll0825/capital_observatory.git
cd capital_observatory

# 2. 配置数据源密钥（FRED 必需；AlphaVantage/Telegram 可选）
export FRED_API_KEY=your_free_fred_key
export ALPHAVANTAGE_API_KEY=your_alpha_key

# 3. 启动全栈（TimescaleDB + Core + API + 4 采集插件）
make dev-up

# 4. 浏览器访问 http://localhost:8080/ (宣传页) 或 http://localhost:8080/app (工作台)
