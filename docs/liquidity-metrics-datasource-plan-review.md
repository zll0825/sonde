# 资本流动性指标与数据源方案审核

审核日期：2026-09-07。对象：[原方案](./liquidity-metrics-datasource-plan.md)。代码基线：`f1408cb`。

**结论：方向基本合理，可保留为候选指标池；目前不宜直接作为接入与预警规则的实施依据。** 需要先修正数据口径、授权与历史范围、发布时间、指标解释和静默上线机制，再补成逐指标的数据字典。

本次通读方案与任务 PRD，核对了现有采集、检测、通知代码，并独立抽查关键官方页面及公开 API。下文区分接口样例与官方文档核验，不将单次 HTTP 200 当成生产可用性证明。P1 表示进入实施前需修正，P2 表示影响完整性或实施成本。

## 1. P1：TGA 实测数值取了日初余额

位置：原方案第 142 行，以及第 200—203 行净流动性表达式。

同一日期的 Treasury FiscalData 响应如下，单位均为百万美元：

| 2026-09-03 的 account_type | open_today_bal |
|---|---:|
| Treasury General Account (TGA) Opening Balance | 944,364 |
| Total TGA Deposits (Table II) | 336,240 |
| Total TGA Withdrawals (Table II) (-) | 376,676 |
| Treasury General Account (TGA) Closing Balance | 903,928 |

原稿引用的 `944,364M` 是日初余额。若净流动性使用当日日终口径，应取 `903,928M`，相差 **404.36 亿美元**。该响应的 `close_today_bal` 为字符串 `"null"`，日终值仍放在 `open_today_bal`；必须同时按 `account_type` 选行，不能仅凭字段名取值。历史回填还需检查表结构变更。

修改建议：在指标字典写明日初/日终口径、筛选条件、值字段、单位转换及历史兼容规则；日初余额若另有用途，应单独命名和标注时间。

证据：[Treasury 原始 API](https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v1/accounting/dts/operating_cash_balance?filter=record_date:eq:2026-09-03&page%5Bsize%5D=20)。

## 2. P1：FRED 的免费访问被误写成统一的开放许可，并遗漏历史限制

位置：原方案第 140、262 行。

FRED 是分发平台，各序列保留各自的数据来源与使用条件。`BAMLH0A0HYM2`、`BAMLC0A0CM`、`BAMLEMCBPIOAS` 的页面均注明 ICE 数据供内部使用，对外发布、分发或提供给第三方需事先获得许可。不能统一归为“美国政府公开数据，无署名义务”。个人内部研究与公开产品展示要分开评估。

这三项页面还均注明：**自 2026 年 4 月起，序列仅包含三年观测**。原稿未列历史起止范围，会使长期压力情景回测与历史分位数方案超出免费来源的覆盖能力。

修改建议：逐序列记录原始提供方、许可链接、内部使用/外部展示条件、署名要求和历史覆盖。对于受限序列，明确使用边界或替代来源，不能因 FRED API 可访问就给出统一许可结论。

证据：[HY OAS](https://fred.stlouisfed.org/series/BAMLH0A0HYM2)、[IG OAS](https://fred.stlouisfed.org/series/BAMLC0A0CM)、[EM OAS](https://fred.stlouisfed.org/series/BAMLEMCBPIOAS)。

## 3. P1：中国 M1/M2 的派生口径不完整，跨 2025 年可能出现假信号

位置：原方案第 120—126 行。

剪刀差通常指 **M1 同比增速 − M2 同比增速，单位为百分点**，不是两个余额相减。M1 包含在 M2 内，余额之差不会按原文描述“转正”。必须把存量指标与增速指标分开命名，并说明采用官方可比增速还是自行计算。

自 2025 年 1 月起，M1 纳入个人活期存款和非银行支付机构客户备付金。不能直接拼接新旧口径余额，再计算同比或历史分位数。官方可比增速与可比历史余额应分别核实。

另外，M1/M2 是货币供应量，不能称作“基础货币”；DR007 是市场利率，LPR 是贷款报价利率。中国融资压力指标应补充政策锚，例如 DR007 相对央行 7 天逆回购操作利率的利差。M2/社融原始统计应优先研究人民银行发布渠道，不能仅因国家统计局 easyquery 失败就转向非官方接口。

证据：[国家统计公报注释 53，政府网刊载](https://www.gov.cn/lianbo/202602/content_7059980.htm)。

## 4. P1：只规定 forward_fill，仍会产生前视偏差和不可比数据

位置：原方案第 50—59、140—144、195—210 行。

频率对齐没有解决“当时是否已发布”“周平均还是时点余额”“单位是否一致”等问题：

| 项目 | 本次核实 | 对方案的影响 |
|---|---|---|
| WALCL / WTREGEN / WRESBAL | WALCL 是周三时点；后两者是周平均 | 日期相同也不能当作同一时点的资产负债表恒等式 |
| SOFR | 使用前一工作日交易数据，约美东 08:00 发布 | “当日”需区分发布日期与有效日期 |
| OFR FSI | 官方明确滞后两个工作日 | 原稿“当日”错误 |
| COT | 通常周二持仓、周五发布 | 历史信号不能提前放到周二 |
| JPNASSETS | FRED 为月末数据，单位为一亿日元 | 不能用该来源兑现“旬频 BOJ、周频全球央行实测值” |

修改建议：记录观测期、首次可用时间、抓取时间、修订版本、原始单位及转换倍率；按信号时点可获得的数据运算，设置最大允许陈旧时间，保留派生值的输入来源。周/月数据前填出的日频值应标明估计属性。FRED 金额单位与 NY Fed 原始美元金额也必须分别归一化。

证据：[WALCL](https://fred.stlouisfed.org/series/WALCL)、[WTREGEN](https://fred.stlouisfed.org/series/WTREGEN)、[WRESBAL](https://fred.stlouisfed.org/series/WRESBAL)、[SOFR 方法](https://www.newyorkfed.org/markets/reference-rates/additional-information-about-reference-rates)、[OFR FSI](https://www.financialresearch.gov/financial-stress-index/)、[CFTC 说明](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm)、[JPNASSETS](https://fred.stlouisfed.org/series/JPNASSETS)。

## 5. P1：将研究假设写成确定因果，容易形成错误告警

位置：原方案第 50—54、67—70、95—108、121 行。

- `WALCL − TGA − RRP` 是简化代理，不是可投资资金的完整会计定义；未提供样本、收益率/水平值口径、滞后与样本外检验，不能断言“与 SPX 相关性远高于任何单项”或预先确定为价值最高指标。
- SRF 使用量大于零不能直接等同“公开市场借不到钱”或“准备金稀缺硬证据”。需区分操作类型、日内融资需求、相对融资价格及技术性因素；应与融资利差、持续时间及规模联合解释。
- 稳定币供应扩张不能一概等同新增法币入场，还要区分法币储备型、加密抵押型等机制，避免跨链重复统计。
- VIX3M/VIX、HY/VIX 背离、M1/M2 剪刀差可以保留为候选信号，但“最可靠择时”“信用市场通常是对的”“中国最有效”等判断缺乏验证依据。

修改建议：每个指标增加“测量对象、可能解释、混杂因素、不能推出的结论、验证方法”。准备金数量与融资价格联合观察可优先实施；净流动性代理先验证增量信息再升级为核心告警。

证据：[纽约联储常备回购说明](https://www.newyorkfed.org/markets/repo-agreement-ops-faq)、[2026 年对手方调查](https://tellerwindow.newyorkfed.org/2026/05/14/surveys-suggest-improved-willingness-by-counterparties-to-use-standing-repo-operations/)。

## 6. P1：静默上线要求缺少对应能力，两周观察不适合低频指标

位置：原方案第 260 行。

当前 `cmd/core/main.go:139` 对触发事件记入噪音统计，`:234` 调用通知器，途中没有按 `severity: info` 排除通知。原稿虽然同时要求“不推送”，但没有说明如何实现；仅修改严重程度无法满足这项约束，也不会自动豁免真实告警预算。

修改建议：首批明确采用禁用规则、只采集，或实现单独的观察模式，并定义是否落告警、计预算和触发通知。验证后再开启告警。月频指标两周内可能没有新观测，周频只有约两点；阈值应结合历史回放、压力样本及足够的新发布期标定。

## 7. P2：缺少真正的交易流动性与资金流量，覆盖仍不完整

位置：原方案第 79—130 行。

VIX、持仓与市场宽度主要是风险和仓位代理，不能代替买卖价差、深度、成交冲击与资金申赎。宏观经济中的实体融资，以及微观经济中的企业/居民融资状况也较薄弱。

| 建议补充方向 | 可研究的免费来源 | 本次核验及边界 |
|---|---|---|
| 银行存款、信贷、现金资产与借款结构 | 美联储 H.8；FRED 对应系列 | H.8 官方当前表 HTTP 200，存在对应分项；具体机器端点另核验 |
| 实体融资供给与需求 | 美联储 SLOOS；人民银行社融、分部门贷款 | 候选补充，未在本次逐项探测 |
| 跨境证券投资与银行资金流 | 美国 Treasury TIC；中国外汇局结售汇、涉外收付款 | TIC 官方页面 HTTP 200；低频、存在滞后，不能完整替代 EPFR |
| 国债发行、到期与财政现金变动 | Treasury 拍卖与财政数据 | 候选补充，用于解释 TGA 扰动；具体接口另核验 |
| 买卖价差、订单簿深度、成交冲击 | 交易所公开盘口；日线 OHLCV 计算 Amihud 等代理 | 需分别核验访问、许可、历史深度；代理不能冒充真实盘口流动性 |
| ETF 申赎与货币基金规模 | 发行人份额/NAV、ICI 等公开统计 | 候选补充，须核验许可和份额口径；ETF 二级成交额不等于净流入 |

北向季度持股市值变化包含价格效应，成交总额没有买卖方向，两者均不能直接替代净流入。OKX 单交易所、单合约 OI 也应显式标记覆盖范围，不能直接命名为全市场 BTC 杠杆总量。

证据：[H.8](https://www.federalreserve.gov/releases/h8/current/)、[Treasury TIC](https://home.treasury.gov/data/treasury-international-capital-tic-system)。

## 8. P2：通用派生引擎不应未经比较就成为所有接入的前置

位置：原方案第 189—219、227—241 行。

“检测器只接受单指标”不等于“插件不能生产派生指标”。现有 crypto 采集器已经计算并上报 `btc.ass.flow_proxy`；宏观插件也有 FRED 同比变换配置。缺口应准确表述为通用的跨来源、跨频率派生编排与血缘管理。

原始准备金、SOFR、信用利差等可以独立接入。少量必要派生可以先比较插件内计算与通用引擎两种方案。VIX3M/VIX 比值生成后，现有 `threshold` 已可检测 `< 1`；如果需要严格的“首次穿越事件”，再论证额外检测器。通用引擎可能值得建设，但应单独估算成本、依赖与收益。

同时修正现状：系统已有 Fed 资产负债表、交易量和链上数量，不能说 16 项都只测价格；`btc.ass.flow_proxy` 仍在采集，“替代已退役合成 flow”需明确指的是哪个旧指标及迁移方式。

## 9. P2：当前大表是来源目录，还不是逐指标接入合同

位置：原方案第 134—183 行。

一行 FRED 包含多个频率、单位和许可不同的序列；多个端点仍写为 `...`，贴现窗口、USD/CNH 等也缺少可执行映射。HTTP 成功不证明目标字段非空、历史足够、许可明确或可持续采集。

建议最终每个指标一行，至少包含：

`metric_id｜测量类别与地域｜存量/流量/价格/代理｜原始提供方｜主/备源｜series/reportName/完整请求｜字段与筛选条件｜原始单位→标准单位｜派生公式｜观测频率｜发布时间/时区/滞后｜历史起止及修订｜认证/配额｜使用条件/许可链接｜实测时间/响应摘要｜优先级/验收条件`

数据源状态建议分成“接口已验证”“下载文件可用”“文档已确认、接口待测”“当前环境访问失败”“使用条件待核实”。FINRA 可下载 XLSX 不应因缺少 API 就归为不可用；单次封锁不能推出全球无可用来源，未找到免费替代也不等于不存在。

本次复测确认 RRP 的 2026-09-04 接受量为 675,000,000 美元，SOFR 返回分位数字段；TFTC 返回 CC BY 4.0 声明、美元单位及截至 2026-09-04 的数据。TFTC 同时注明来源混合 SoSoValue 与 Farside 整理数据，不能笼统当作 Farside 的等价镜像。CFTC Socrata 本次返回 403，而 CFTC 官方报告页可访问；这说明需要保存探测条件并准备官方批量下载路径，不能据此否定此前可能成功的探测。

## 建议修订顺序

1. 修正 TGA、M1/M2、许可、历史范围和发布时间，补逐指标数据字典。
2. 第一批交付准备金、融资利率/利差、TGA/RRP 与少量必要派生，明确只采集或观察模式；净流动性代理保留为待验证项。
3. 补银行信用、跨境资金流和交易流动性方向；为中美各保留最小观测闭环，不只按接口易用程度排序。
4. 历史与实时样本证明有效后，再扩展仓位、加密数据和告警；通用派生引擎作为独立设计决策评估。
